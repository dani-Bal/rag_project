# Contributing

## Workflow

`main` is the protected primary branch. Work on feature branches such as
`feature/document-ingestion` or `fix/retrieval-filtering` and submit every change through a pull
request.

Pull requests should be small and focused, have at least one review, and pass CI before merging.
Use squash merging. Write clear, descriptive commit messages; Conventional Commits are welcome
but not required.

## Definition of done

- Requirements are implemented and new functions are typed.
- Public interfaces have suitable docstrings.
- Relevant tests and documentation are updated.
- Ruff, Pyright, pre-commit, and CI pass.
- The pull request has been reviewed.
